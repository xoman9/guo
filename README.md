# guo

### 下载位置与文件结构（1.0.3+103）

设置 → 下载 → 下载目录与空间，管理员可使用 Android 系统资料夹选择器，或授权后使用共享的 `Download/guo`。系统选择器目前支援内部共享储存，尚不支援外接 SD 卡；原有应用私有目录与迁移入口继续保留。更换目录不移动或删除旧文件，只显示新位置的下载索引；切回本应用原目录可恢复查看，拒绝打开其他应用已有索引的目录。

| 内容 | 相对下载根目录的路径 |
| --- | --- |
| 正在下载或转换的原始分集 | `剧名/0001/media.mp4` 或 `剧名/0001/index.m3u8` 与分片、金钥 |
| 转换成功的分集 | `剧名/第1集.mp4` |
| 选取连续分集合并的成品 | `剧名-合.mp4`，重名时为 `剧名-合 (1).mp4` |

按站源分类开启时，分集路径前再加站源目录。同名不同剧集使用不同剧名目录，非法文件名字元会替换。转换成功且下载索引保存成功后删除原始分集与金钥；失败时保留原始资料以便重试。合并入口在「下载 → 已下载 → 剧集 → 编辑」，选取连续且编码、尺寸一致的已完成分集；合并成品验证、保存成功后，会删除所选原分集 MP4、其下载产生的文件及空资料夹；保留未选取的分集。清理失败时合并成品仍保留，并显示路径与错误。

参考来源为 [oktv 指定提交](https://github.com/xoman9/oktv/commit/1ba9d1e69de77f62588af3d9763d1858d62aa98c) 的完整快照，仅适配下载相关行为，未引入其剧库备份容量变更。Android 权限与系统选择器、真实站源的下载和合并效果尚待真机验证。

黄豆、帝果、剧果、野果及黄果相关频道名称以单一符号 🔞 标记；取片核心及既有站源开关不变。
