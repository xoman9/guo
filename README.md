# guo

### 下载位置与文件结构（1.0.3+103）

设置 → 下载 → 下载目录与空间，管理员可使用 Android 系统资料夹选择器，或授权后使用共享的 `Download/guo`。系统选择器目前支援内部共享储存，尚不支援外接 SD 卡；原有应用私有目录与迁移入口继续保留。更换目录不移动或删除旧文件，只显示新位置的下载索引；切回本应用原目录可恢复查看，拒绝打开其他应用已有索引的目录。

| 内容 | 相对下载根目录的路径 |
| --- | --- |
| 正在下载或转换的原始分集 | `剧名/0001/media.mp4` 或 `剧名/0001/index.m3u8` 与分片、金钥 |
| 转换成功的分集 | `剧名/第1集.mp4` |
| 选取连续分集合并的成品 | `剧名-合.mp4`，重名时为 `剧名-合 (1).mp4` |

按站源分类开启时，分集路径前再加站源目录。同名不同剧集使用不同剧名目录，非法文件名字元会替换。转换成功且下载索引保存成功后删除原始分集与金钥；失败时保留原始资料以便重试。合并入口在「下载 → 已下载 → 剧集 → 编辑」，选取连续且编码、尺寸一致的已完成分集；合并成品验证、保存成功后，会删除所选原分集 MP4、其下载产生的文件及空资料夹；保留未选取的分集。清理失败时合并成品仍保留，并显示路径与错误。

参考来源为 [oktv 指定提交](https://github.com/xoman9/oktv/commit/1ba9d1e69de77f62588af3d9763d1858d62aa98c) 的完整快照，仅适配下载相关行为，未引入其剧库备份容量变更。Android 权限与系统选择器、真实站源的下载和合并效果尚待真机验证。

黄豆、帝果、剧果、野果及黄果相关频道名称以单一符号 🔞 标记；取片核心及既有站源开关不变。

### lujj31.lol（待网站接口验证）

新增独立的 `lujj31` 站源入口，网址固定为 `https://lujj31.lol`，管理员需在「设置 → 站源」手动开启，不会预先下载剧库。已参考 `xoman9/oktv` commit `1ba9d1e69de77f62588af3d9763d1858d62aa98c` 的 **桃果（taoguo）** 网页解析方式，改接 `/index.php/vod/type/id/` 分类、`/index.php/vod/detail/id/` 详情、`player_aaaa` / `player_data` 播放页。不再请求先前错误假设的 `/api.php/provide/vod/` JSON 接口。预设关闭，不预载剧库；只有明确的 MP4/M3U8 媒体才可进入播放器，其他站源不受影响。**网页实际回传内容及播放仍需真机验证。**

GitHub Actions 于 2026-10-29 对 `lujj31.lol` 与此前提供的 `lujj31.buzz` 进行只读探测，两者在当时的云端网络都解析到相同地址，首页及先前误测的 JSON 接口均返回 `HTTP 200` 但回应体为零字节；`www.lujj31.lol` 的 TLS 证书不匹配。**这不证明该站可播放，也不证明其他地区必然相同。** 因此新站源保持默认关闭，禁止将空白回应视为有效剧库。详见 `.github/workflows/probe-lujj31.yml` 与对应 Actions 记录。


1.0.5+105：下載後合併先讀取全部分集的媒體資訊，以最低解析度統一影音格式；進度顯示預備、格式不符轉檔與合併集數。不做額外時長／完整解碼驗證。成品存於下載資料夾，檔名為「片名(起集-迄集).mp4」，成功後清理原分集、下載時產生的檔案、空資料夾及合併暫存；失敗保留原分集。同名成品加序號保留。只修改本地媒體處理，實機驗收待完成。

1.0.6+106：下載頁「下載中／已下載」同列最右側顯示所有下載任務的合計即時下載速度，約每 2 秒更新。以分集已下載位元組增量計算；暫停、沒有傳輸或讀取狀態失敗時歸零，不把既有已下載資料或重新下載前的累計量當成新流量。

1.0.7+107：合併只轉換格式不相容的分集，目標格式已相同的分集直接複製碼流。未加密的單檔影片直接讀取資訊，不再先完整換封裝一次；加密／HLS 分集保留原預備流程。必要轉碼使用 ultrafast 與最多 4 個編碼執行緒，保留原畫質參數；快速編碼的成品可能較大。實機速度待測。

1.0.8+108：Android 10 以上合併必要轉檔時，H.264／8-bit SDR 優先使用系統回報的硬體 AVC 編碼器。先檢查尺寸、幀率、色彩格式與位元率支援，指定實際硬體元件交由 FFmpeg MediaCodec 編碼；不支援或初始化失敗時回退 CPU，取消不觸發回退。進度顯示硬體／CPU 轉檔狀態。相容分集仍直接複製，保留下載網速顯示、最低解析度、範圍檔名與完成清理。硬體啟用與速度需實機確認。
必要的 8-bit SDR 影片格式統一以 H.264／AVC 為目標，避免改用較慢的 HEVC 軟體編碼；完全相同而無需轉碼的 HEVC 分集仍直接複製。

1.0.9+109：整批一般未加密分集的封裝、串流順序、編碼參數、時間基準與編碼標頭完全相容時，直接以原檔清單合併，不產生暫存分集、不轉碼。混合格式、加密或 HLS 沿用統一流程。原檔路徑支援空白及引號；成品優先以同儲存位置重新命名發布，失敗才複製。成功後才清理原分集，保留硬體優先、下載網速、最低解析度與集數範圍命名。

1.0.10+110：合併任務由應用內下載管理層持有，關閉合併視窗、離開影片頁及切換頁面不取消任務；只有明確取消或關閉下載管理生命週期時才停止。下載頁與影片頁保留進度入口，完成／失敗後可重新查看結果及路徑，不自動彈窗或退出目前頁面。切換使用者會停止該使用者的任務並隱藏結果。此功能不保證系統終止 APP 後仍能執行。
